本四足机器人机身采用碳纤维材质、腿部采用钢板整板切割工艺制作，详细结构可参考robot结构图，整机搭载小米CyberGear电机作为腿部动力单元，以英伟达Jetson Nano为主控核心，设备基于CAN总线实现全域通信控制，其中主控核心程序为Robocon.py，库函数支持程序为lib2.py；设备默认采用Trot对角小跑步态运行，腿部大小腿电机采用同轴交错联动运动机制，依托精准的电机时序配合保障行走姿态稳定，工作时由Jetson Nano主控通过CAN总线向各关节电机下发运动指令，实现全腿关节协同控制，为方便程序调试、参数适配与故障定位，所有电机需提前完成统一编号标定，将唯一电机ID固化于控制代码中。为解决单USB转CAN模块带宽不足、抗干扰性差导致的通信丢帧、电机离线、指令中断等问题，设备调试与运行阶段统一采用双USB转CAN模块搭建通信链路，保障CAN总线通信连续稳定，设备所用电机驱动函数均由厂商封装完成，可直接在主控程序中调用，同时搭配官方上位机可实现电机ID修改、单电机测试、参数校准等前期调试操作。设备正式上电及步态调试前，需进入专属校准模式完成整机初始姿态校准，可借助板凳等辅助工装固定机身姿态、规避校准偏差，保证各关节电机精准归零，为后续步态运算与运动控制建立统一基准。因机身碳纤维材质具备导电性，为杜绝短路、漏电、设备损坏等安全问题，整机电池、各类传感器及供电线路等所有带电模块均需做全维度绝缘防护处理。设备全程通过Nomation远程控制软件完成远程调试、指令下发与状态监控，装配时需将Jetson Nano主控安装于通风、无遮挡的开放环境，严禁布置在密闭空间，避免远程通信信号受干扰，出现桌面卡顿、指令延迟、通信断连等问题，保障设备调试及运行稳定性。
