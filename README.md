1.材料:腿部为钢板整板切割而成,机身为碳纤维材料,详细结构见图robot  

2.电机类型:小米CyberGear

3.主控:英伟达 Jetson nano

4.通信方式:Can总线通信

主控核心代码:Robocon.py

库函数代码:lib2.py

  本机器人采用Trot对角小跑步态作为基础运动步态，腿部大小腿电机采用同轴交错联动运动机制，通过精准的电机时序配合实现稳定的行走姿态。
设备整体采用主控+CAN总线分布式控制架构，由主控单元通过CAN总线向各关节电机下发运动控制指令，实现全腿关节的协同运动控制。为便于后续程序调试、参数适配与故障定位，所有关节电机需提前完成统一编号标定，电机ID将作为程序控制的唯一寻址标识，固化至控制代码中。
  项目调试与运行阶段统一采用双USB转CAN模块架构搭建通信链路。经实测，单USB转CAN模块通信带宽与抗干扰能力不足，易出现通信丢帧、电机离线、运动指令中断等不稳定问题，双模块配置可有效规避信号干扰问题，保障CAN总线通信的连续性与稳定性。
项目所用电机驱动函数均由厂商封装完成，无需底层驱动开发，可直接在主控程序中调用接口实现电机运动控制；同时配套官方上位机，支持电机ID修改、单电机动作测试、参数校准等基础功能，为前期硬件调试提供支撑。
  机器人正式上电运行、步态调试前，必须执行整机初始姿态校准，进入专属校准模式，确立机器人运动基准状态。
校准姿态可选取机器人可稳定维持的任意标准姿态，调试过程中可借助板凳等辅助工装完成机身支撑与姿态固定，规避悬空、受力不均导致的校准偏差，确保所有关节电机归零精准，为后续步态运算、运动控制提供统一基准。
  机器人腿部结构优选碳纤维材质。相较于传统钢板材质，碳纤维轻量化优势显著，可有效降低腿部运动惯量，提升机器人步态响应速度与运动灵活性，同时减少整机负载，降低电机功耗。
  碳纤维具备导电特性，存在电路短路、传感器损坏等安全隐患。因此机器人整机所有带电模块，包括电池、各类传感器、供电线路等，必须完成全维度绝缘防护处理，杜绝碳纤维结构接触带电部件引发的短路、漏电、设备故障等问题。
  本项目基于Nomation远程控制软件完成机器人远程调试、指令下发与状态监控。
  在整机结构装配阶段，主控单元严禁安装于密闭、封闭空间。密闭环境会严重干扰远程通信信号，导致远程桌面连接卡顿、指令延迟、通信断连等问题，直接影响调试效率与设备运行稳定性，需保证主控安装位置通风、信号无遮挡。
- 所有关节电机提前编号标定，固化ID至程序，便于调试与故障排查；
- 固定使用双USB转CAN模块，保障CAN总线通信稳定，避免电机离线、丢帧；
- 上电调试前必须完成整机姿态校准，建立统一运动基准；
- 碳纤维结构整机必须做好电气绝缘防护，规避短路风险；
- 优先选用碳纤维腿部结构，优化整机轻量化与运动性能；
- 主控开放式安装，保证远程通信信号稳定，适配远程调试需求
