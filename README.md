1.材料:腿部为钢板整板切割而成,机身为碳纤维材料,详细结构见图robot
2.电机类型:小米CyberGear
3.主控:英伟达 Jetson nano
4.通信方式:Can总线通信
主控核心代码:Robocon.py
库函数代码:lib2.py
首先定好机器人trot的运动步态与大小腿电机同轴交错运动的方式，由主控通过Can总线通信的方式给每个电机发送信号，前期的话需要给电机编号好，后续在代码中方便调试，其次最好用到两个Usb转Can的模块，因为我们测试过仅有一个的话会导致信号不稳定，出现掉帧的情况，容易有电机掉线。电机函数都是由商家封装好的，直接调用即可，也有上位机可对电机编号与测试。在测试的时候，一定要设置一个初始状态，也就是校准模式，可以是任何可以让机器人达到的状态，也可以借用工具例如板凳进行辅助校准，这是机器人运行前的基准。要注意碳纤维是可以导电的材料，机器人身上的所有带电传感器包括电池必须要进行绝缘处理。其次我们建议机器人腿部也设置为碳纤维，因为钢板实在是太重了。我们机器人调试的方式主要用到nomation软件进行远程控制，后期建议在机器人结构搭建的时候，不要将主控放在密封环境，会导致远程桌面信号的不稳定。本机器人项目没有采用到IMU，建议运动逻辑成熟后，加入姿态传感器与PID控制，降低机器人运动中电机转动的角度误差。
