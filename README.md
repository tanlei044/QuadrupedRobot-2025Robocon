本项目由楼主团队从2024年11月开始准备，前期主要由负责机械的同学进行机身的设计，到2025年4月左右，楼主开始进行电机的调试与机身的控制，共历时7个月，最终获得了包括全国大学生机器人大赛三等在内的多项荣誉。写这篇帖子的目的，一方面是想给有志于从生四足机器人开发的伙伴提供一些经验，一方面是想通过文字的方式留下大三暑假这段珍贵的记忆。当然，由于项目正处于入门级，更适合那些处于入门并且想直接入手的同学。希望团队的经验能对你有所帮助。

3.主控：英伟达 Jetson nano
